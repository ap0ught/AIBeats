# The cartridge goes here

Put your own dump of the game in this directory as:

```
Battletoads (USA).nes
```

The file is **never committed** — `.gitignore` excludes `*.nes`.

## Hash

BizHawk should identify it as SHA-1 `5C3A497A82BE60704DEDF45248B6AD9B32C855AB`.

To check what you have:

```
sha1sum "Battletoads (USA).nes"
```
